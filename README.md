# Accessible Card Checkout Form

A simple checkout form built with React, TypeScript, Vite and Tailwind CSS. It checks that card details are entered correctly: the number (Luhn check and length), the expiry date, the CVV and the name. It also shows the card network as you type. It works with a keyboard and screen readers.

> **No real card data is handled.** Nothing is sent or stored. Use test numbers only, such as `4111 1111 1111 1111`.

## Run locally

```bash
npm install
npm run dev
```
